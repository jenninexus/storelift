# Creator Demo Kit

This starter kit accompanies the StoreLift sandbox storefront. It contains two reusable worksheets for a creator getting a small catalog ready for checkout.

1. Copy `catalog-template.csv` and give each product a stable SKU.
2. Use `launch-checklist.md` to check product intent, checkout and delivery.
3. Test the path from product detail to receipt with separate sandbox buyer and merchant accounts.

The worksheets are original to StoreLift and covered by its MIT license.
