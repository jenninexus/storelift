# Creator launch checklist

- [ ] Identify the source catalog and confirm permission to reuse its text and media.
- [ ] Keep each free link, optional tip and paid download visibly distinct.
- [ ] Write the title, contents, version and support contact for each paid file.
- [ ] Check that the storefront shows the approved price and currency.
- [ ] Run one sandbox purchase and verify the receipt and downloaded file.
- [ ] Try cancellation, a repeat request and an expired download link.
- [ ] Review what a buyer sees on mobile and with a keyboard.
- [ ] Save the exact source revision and instructions for reproducing the demo.
